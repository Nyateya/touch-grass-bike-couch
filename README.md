# 🚲 Touch Grass: Offline AI Cycling Coach

An offline-first, open-weight AI assistant built for cyclists and outdoor adventurers. Powered locally by **Llama 3.2** and **Ollama**, this tool generates custom trail recommendations, gear checklists, and safety guides without requiring an internet connection.

## 🌟 Why "Touch Grass"?
Modern fitness apps rely heavily on cloud APIs, constant connectivity, and data tracking. This project takes the opposite approach: **privacy-first, edge-computed outdoor intelligence** that helps you unplug, get outside, and stay safe on the trails.

## 🛠️ Tech Stack
* **Python** (`py`)
* **Ollama** (Local inference engine)
* **Llama 3.2 (3B)** (Open-weight model running locally on-device)
